## 3. Game Design & Core Mechanics

### Progression & Economy (`src/game/constants.ts`)
- **Upgrade Cost Curve:** `cost = floor(baseCost * (costMultiplier ^ owned))`
  1. **自動打工腳本 (Auto Script):** Base `15`, Multiplier `1.15`, `+4 TPS`
  2. **升級 GPU 伺服器 (H100 Rack):** Base `120`, Multiplier `1.18`, `+18 TPS`, `+2 Click`
  3. **招募 AI 工程師 (Prompt Team):** Base `1,100`, Multiplier `1.20`, `+95 TPS`, `+10 Click`
  4. **RLHF 數據飛輪 (Data Flywheel):** Base `12,000`, Multiplier `1.22`, `+540 TPS`, `+45 Click`
  5. **AGI 超算集群 (AGI Cluster):** Base `130,000`, Multiplier `1.25`, `+3,200 TPS`, `+250 Click`
- **Startup Evolution Stages:**
  - `0+` 車庫獨立開發者 (Garage)
  - `500+` 種子輪新創 (Seed)
  - `10,000+` A 輪高速成長 (Series A)
  - `250,000+` AI 獨角獸 (Unicorn)
  - `5,000,000+` AGI 奇點帝國 (Singularity)
- **Critical Hits & Combo:** 12% crit chance per click (`3x` output, white hit-flash, 35ms hitstop, camera shake). Rapid clicks (<450ms) raise synth pitch smoothly up to 20 combo stacks.
- **Golden VC Packet:** Spawns every 18–32 seconds during active play; rewards `max(150, floor(TPS * 25))` instant Tokens.
- **Monetization Loops:**
  - **5-Minute 10x Fever Mode (`FEVER_DURATION_SEC = 300`, `FEVER_MULTIPLIER = 10`)** triggered via Rewarded Ad flow.
  - **Offline Earnings:** Calculates `50%` of passive TPS during absence (15s minimum, capped at 8 hours) with a **2x Rewarded Ad** option.

## 4. Design Mode & Customization How-To

Want to rebalance the economy, re-skin the visuals, or plug in a live Ad SDK? Everything is modular:

1. **Tune Economy & Stages (`src/game/constants.ts`):**
   - Edit `UPGRADES` to add new tiers, adjust `costMultiplier`, or tweak `baseTps` / `clickBonus`.
   - Edit `STARTUP_STAGES` to customize milestone names and badge colors.
   - Change `FEVER_DURATION_SEC` or `FEVER_MULTIPLIER` to adjust boost strength.
2. **Customize Canvas Visuals (`src/components/GameCanvas.tsx`):**
   - Adjust `primary` (`#22d3ee` cyan / `#fbbf24` gold in fever) and `secondary` (`#34d399` / `#f97316`) colors, grid spacing (`gridSize = 48`), or particle pool size (`PARTICLE_POOL_SIZE = 160`).
3. **Modify Procedural Audio (`src/audio/synth.ts`):**
   - Customize oscillator waveforms (`sine`, `triangle`, `sawtooth`) and note frequencies for clicks, upgrades, and golden catches.
4. **Connect Real Monetization SDK (`src/App.tsx`):**
   - Replace the simulated 3-second countdown inside `startFeverAd` / `claimAdReward` with `window.CrazyGames.SDK.ad.requestAd('rewarded', ...)` or your GamePix / Google H5 Games AdSense callback.

## 5. Technical Spec

- **Frontend Stack:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Vite 8 (`base: './'` for portable relative-path portal bundles).
- **Render Loop:** Isolated 60fps `requestAnimationFrame` `<canvas>` with clamped delta time (`Math.min(rawDt, 0.05)`), DPR scaling, and zero-allocation pooled particles/floating text.
- **Persistence:** `localStorage` (`ai_startup_sim_save_v1`) auto-saved every 5 seconds.
